Colour

Black is black. Purple is the pen. Blue is the signal.

What each colour means

Black

Ground and ink. At least 92% of any screen. Used for the page, text, rules and node outlines. Never tinted, never a gradient, never swapped for a dark grey page.

Purple

The pen: what was decided, built or chosen. One primary action per screen, own-code nodes, rule numbers, the current-page mark, the trace marker, selection. Never for links, running text, or any fill larger than a button.

Blue

The signal: what links, flows or is measured. Links, focus, data-flow edges, the trace line, the footer rule. Never for buttons, headings or decoration.

Proportion

Black and ink about 70, purple 20, blue 10, by eye.

By area, at least 92% of any screen is neutral. Of the coloured rest, two thirds is purple and one third blue.

System diagrams

One vocabulary for every case study. The signature interaction is the trace: step through a request, one hop at a time.

Not started

Select a node to read what it is, or trace the request from the first hop.

  1. A message arrives by webhook. The intake API checks the signature and drops duplicates.
  2. Valid messages become jobs on a queue, so the caller gets an answer without waiting for the model.
  3. A worker pulls one job at a time. If it crashes, the job goes back on the queue.
  4. The worker asks a self-hosted model to classify the message and draft a reply.
  5. Every decision is appended to the audit log, so any outcome can be explained later.
  6. The worker writes the result to the booking system. If that times out, it retries with backoff, then parks the job for a human.

Failure note

What broke

I assumed the queue kept messages in order. It did not, so ordering became the consumer's job. The consumer now has a test that fails when it is not.

The rule draws a burst of noise, then goes flat, like the hero line. The old belief is struck through and the correction is underlined in purple.

Margin note

Prose keeps to its measure. A note that belongs to a paragraph sits beside it in the margin, in the drafting voice, and drops below the paragraph on narrow screens. Notes are for one or two lines, never for content the reader must not miss.

Note. Two lines at most. If it is longer, it is body text.

Code

Martian Mono is used only here and in inline code like seen(key). Blocks are square, scroll sideways on narrow screens, and can be focused with the keyboard.

Motion

One moment the visitor did not ask for. Everything else answers an action.

The one orchestrated moment

On first load the hero line draws once, left to right, then the purple marker appears where the noise ends. It takes 1.6 seconds, does not loop, and never repeats on navigation.

Budget

  • One motion the visitor did not trigger per site: the hero line.
  • Diagram tracing plays only after a click, runs once through, and stops. No loops.
  • No scroll reveals, no parallax, no hover lifts, no cursor effects, no auto-playing anything.
  • Nothing moves more than 1 px on press. Nothing takes longer than 420 ms except the hero line.
  • With reduced motion on, the hero line is drawn already, and tracing is stepped by hand only.
